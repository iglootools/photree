# Configuration Reference

Every field of photree's optional configuration file: where it is looked up,
which commands read it, each field's type, default and allowed values, and how
invalid values are reported. For the workflows these settings serve, see
[usage.md](usage.md#configuration); for every command-line option, see
[cli-reference.md](cli-reference.md). A complete example is in
[config-examples/config.toml](config-examples/config.toml).

The file is TOML. Everything in it is optional, and every field has a
command-line flag that overrides it, so photree runs without one.

## Location

The first of these that exists is used:

1. the file passed with `--config <path>` — an error if it does not exist
2. `$XDG_CONFIG_HOME/photree/config.toml` (`~/.config/photree/config.toml` when
   `XDG_CONFIG_HOME` is unset, empty or a relative path)
3. the platform user config directory (macOS:
   `~/Library/Application Support/photree/config.toml`; on Linux the same path
   as 2)
4. the platform site config directory (macOS:
   `/Library/Application Support/photree/config.toml`)

## Which commands read it

| Section | Read by | Precedence |
|---|---|---|
| `[importer]` | `album import`, `album import-check`, `albums import`, `albums import-check` | `--source` > `image-capture-dir` > default |
| `[exporter.profiles.<name>]` | `album export`, `albums export`, `gallery export`, when `--profile <name>` is given | each flag (`--share-dir`, `--share-layout`, `--album-layout`, `--link-mode`) > profile value > default |

A searched-for file is read only when a command needs a value from it: an import
given `--source`, or an export given no `--profile`, does not read it, so a
broken file elsewhere does not block them. A file passed with `--config` is
always read and validated, so a path typed by hand is never silently ignored.

## Fields

Path values expand a leading `~` to the home directory. A key or table photree
does not know is an error, so a misspelt key cannot silently fall back to its
default.

The tables below are generated from the config models in
`photree/config/protocol.py` by `mise run configdocs`, and `lint-configdocs`
fails when they are out of date: change a key's description in its field's
`metadata` there, not here.

### `[exporter.profiles.<name>]`

One table per named export profile, selected with `--profile <name>`.

<!-- rumdl-disable -->
<!-- BEGIN CONFIGREF:EXPORTER_PROFILE (auto-generated by: mise run configdocs — do not edit manually) -->
| Key | Type | Default | Description |
|---|---|---|---|
| `share-dir` | string (path), **required** | — | Base directory to export into. |
| `share-layout` | string | `flat` | How albums are arranged under `share-dir`: all side by side (`flat`), by year (`albums`), or by month (`by-month`). Allowed values: `flat`, `albums`, `by-month`. |
| `album-layout` | string | `browsable-jpg` | Which of an album's directories are exported. Allowed values: `browsable-jpg`, `browsable`, `all`, `archive`. |
| `link-mode` | string | `hardlink` | How exported files reference the gallery's files. Allowed values: `copy`, `hardlink`, `symlink`. |
<!-- END CONFIGREF:EXPORTER_PROFILE -->
<!-- rumdl-enable -->

What each layout and link mode produces is described under `album export` in
[cli-reference.md](cli-reference.md#photree-album-export).

Two rules apply to the export settings once flags and the profile are combined,
not to the file on its own:

- `share-layout = "albums"` requires `album-layout = "all"`. Breaking it is a
  usage error and exits 2, as does selecting a profile the file does not
  define, or giving neither `--share-dir` nor `--profile`.
- `share-dir` must contain a `.photree-share` sentinel file, so an export cannot
  write into a directory that was not prepared for it. A missing sentinel
  depends on the disk, such as a volume that is not mounted, and exits 1.

## Errors

A configuration error stops the command with exit code 2, naming the key and
profile at fault (or the file, when it is missing, unreadable or does not
parse):

| Error | Cause |
|---|---|
| file not found | `--config` names a file that does not exist |
| unreadable file | the file exists but cannot be read, such as for lack of permission |
| invalid TOML | the file does not parse, or is not UTF-8 |
| missing key | a profile has no `share-dir` |
| unknown key | a key or table is not one listed above, such as `link_mode` for `link-mode` |
| invalid type | a section is not a table, or a value is not a string |
| invalid value | `share-layout`, `album-layout` or `link-mode` is not one of the allowed values |
